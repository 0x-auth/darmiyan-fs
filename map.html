The spine

Three statements everything reduced to

These were not the starting point. They are what was left after the constructions that failed were removed.

01 Forward is cheap. Reverse has nowhere to live.

Every reference has a direction that costs one lookup and a direction that costs a scan of the world. The reverse answer is not stored anywhere because a name is free to appear anywhere at any time.

30,760× measured
02 Time is accumulated error, not elapsed clock.

A walker's proper time is the sum of its own step-to-step differences. Freeze the system clock and the number does not move by a single bit.

τ = 1.773877583285132
03 Every quantity is a ratio. Nothing supplies the unit.

Λ fixes how fast confidence grows, never what one unit costs. The same gap appears in settlement depth, in proper time, and in the simulation framework.

unresolved, four appearances

Evidence

What was measured

reversefs/mirror_fs.py

A reference has two costs

readlink(p) 0.624 us which names point at p 0.019 s ratio 30,760x

The forward answer is stored at the name. The reverse answer is stored nowhere, so it is reconstructed by visiting everything.

forwardfs/manifold.py · timeless/

Proper time ignores the clock

clock running 1.773877583107473 clock frozen 1.773877583107473 sqrt(pi) 1.772453850905516

Bit-identical under an LD_PRELOAD that freezes every clock read. τ = Σ1/(FnFn+1) by Cassini, not √π: 8.0e-4 apart.

forwardfs/darmiyan.py

Sectors recovered from failure

parabolic -> self-link -> ELOOP rotation -> cycle -> ELOOP boost -> open chain -> no end ELOOP fires at depth 41

Nothing on disk records the sector. The reader finds it by how the walk ends. A shift map is still misclassified, which is the known gap.

forwardfs/nocode.py

A program made of four symlinks

parity/even/0 -> ../even parity/even/1 -> ../odd parity/odd/0 -> ../odd parity/odd/1 -> ../even

The input is the path and the kernel's resolver runs it. No loop over the input anywhere. Capped at 40 components by SYMLOOP_MAX.

forwardcomplexity/boundary.py

A correct field has no traps

BFS field 0 trap cells of 1647 cheap field 1 trap, 6 agents stranded 3-SAT at ratio 5.0 0 / 120 solved

The search did not vanish, it was paid once and became a field. Approximate the field to save that cost and agents get stranded.

forwardcomplexity/recognition.py

Recognition is prepaid structure

blind descent 43/60 28.56 ms recognise + solver 60/60 1.44 ms false positives 0/60

Renamable Horn, detected by a 2-SAT test. My prediction that descent would score zero here was wrong; it got 43.

reversechain/verify.py

There is no hash

f(x) = 1 + 1/x f-1(y) = 1/(y-1) one division each way

A Möbius map is invertible, so nothing commits to anything, so there is no miner. What verifies is the pair, and φ cannot be the validator: jumping to the fixed point passes a φ-check and lies about history.

forwardpair/asym_pair.py

CP exact, T violated

baseline 8.123129892 0.000e+00 CP 8.123129892 0.000e+00 T 5.513863445 2.609e+00 CPT 5.513863445 2.609e+00

All the asymmetry sits in one letter, and that letter is memory. The arrow belongs to the pair: the lossless member has no monotone quantity at all.

narrowedpair/two_systems.py

A conservation law, scoped down

symmetric 3.413296 -> 3.413296 asymmetric 3.436265 -> 12.208663

The conserved residue holds for symmetric pairs and breaks the moment one side scars. The earlier result stands with a smaller domain than claimed.

forwardnumbers/mirrors.py

A base has a mirror, or terminates in nothing

phi conj 0.618 25/25 terminate silver conj 0.414 25/25 sqrt2 conj 1.414 12/25 e none 2/25 pi none 3/25

The mirror of a base is its Galois conjugates. Inside the unit disk means Pisot means integers terminate. A transcendental has no mirror at all.

reversequantum/quantum.py

The operation no base supplies

path via |0> +0.707107 x +0.707107 path via |1> +0.707107 x -0.707107 sum +0.000000

Signed amplitudes cancel. A base relabels, and a permutation cannot annihilate anything. Grover on the 3-SAT that beat descent: 50 calls against 3,276, P(solution) 0.99994535.

nullnumbers/primes_bases.py

Primes look like nothing special

within fixed length, p values 13 0.315 18 0.894 16 0.703 20 0.434 rotation KS p = 0.9577

Nine of ten statistics looked significant until length was controlled for. All of it was prime density, not representation. Expected result written into the file before running it.

Corrections

Seven things that were wrong

Next

Two things worth doing

Build the mirror framework on the Möbius case. Two resolvers over one artifact, both computing Δ, and the whole test is whether they agree. It is the only item that turns the pile into a tool, and the case where every answer is already known.

Add the point at infinity as a real directory. If the shift map's chain then closes onto it, the classifier was right and the chart was incomplete. Closable in an evening, and either answer is useful.
